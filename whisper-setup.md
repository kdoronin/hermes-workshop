# Задача: настроить локальную транскрибацию Whisper в Hermes

Настроить распознавание голосовых сообщений через `faster-whisper`: основная модель `medium`, язык `ru`, повторная проверка сложных записей через `large-v3`. Выполнить настройку доступными инструментами и проверить её через действующий шлюз мессенджера.

Работать только в выбранном профиле. Сохранить остальные настройки. Не переносить чужую память, переписку, аудиозаписи, словари, токены и конфигурацию целиком. Не подключать облачное распознавание без отдельного разрешения.

## 1. Проверить установку

Загрузить навык `hermes-agent`, если он доступен. Сверить поддерживаемые параметры с документацией и исходным кодом установленной версии:

- https://hermes-agent.nousresearch.com/docs/
- https://hermes-agent.nousresearch.com/docs/user-guide/configuration
- `tools/transcription_tools.py` в установленном Hermes.

Выполнить:

```bash
hermes --version
hermes config path
hermes gateway status
hermes doctor
```

Для именованного профиля использовать `hermes --profile PROFILE ...`, подставив фактическое имя. Не переключать глобальный профиль.

Определить Python, которым запускается Hermes. Прочитать только относящиеся к STT настройки; не выводить целиком `.env`, конфигурацию или журналы. Перед изменениями сохранить локальную резервную копию конфигурации с ограниченными правами доступа.

## 2. Проверить и установить faster-whisper

В командах ниже `HERMES_PYTHON` — переменная с найденным абсолютным путём к Python целевой установки. Сначала определить и задать её, не копируя путь с другой машины.

```bash
"$HERMES_PYTHON" -c 'import sys, faster_whisper; print(sys.executable); print(faster_whisper.__version__)'
```

Если библиотека отсутствует, установить её в это же окружение штатным для установки способом. При наличии `pip`:

```bash
"$HERMES_PYTHON" -m pip install faster-whisper
```

Для окружения под управлением `uv`:

```bash
uv pip install --python "$HERMES_PYTHON" faster-whisper
```

Использовать один подходящий способ. Не устанавливать пакет глобально только потому, что его не видит системный `python3`.

Перед скачиванием крупных моделей проверить доступные ресурсы и согласовать расход, если он ещё не разрешён. Первый запуск может загружать веса из сети. Скачивание весов не требует отправки аудио в сервис распознавания.

## 3. Применить настройки

После проверки поддержки полей в установленной версии привести раздел `stt` к следующему виду, сохранив посторонние настройки:

```yaml
stt:
  enabled: true
  provider: local
  local:
    model: medium
    language: ru
    initial_prompt: ""
    vad: true
```

Предпочтительный способ изменения:

```bash
hermes config set stt.enabled true
hermes config set stt.provider local
hermes config set stt.local.model medium
hermes config set stt.local.language ru
hermes config set stt.local.initial_prompt ""
hermes config set stt.local.vad true
```

Проверить результат: `enabled` и `vad` должны быть логическими значениями, `initial_prompt` — пустой строкой. Если CLI некорректно записывает пустую строку, исправить только это поле средствами работы с YAML.

### Параметры распознавания

- `medium` использовать как исходную модель. При нехватке ресурсов сравнить её со `small`; при устойчивых смысловых ошибках проверить `large-v3`. Не менять основную модель только ради одного повторного распознавания.
- `language: ru` фиксирует русский язык и исключает ошибочный выбор другого языка автоматическим определением. Если предполагаются регулярные сообщения на разных языках, отдельно выбрать подходящую языковую политику.
- `vad: true` включает выделение участков речи. При пропуске тихих слов сравнить ту же запись с выключенным VAD.
- `initial_prompt` оставить пустым. Короткий словарь написаний добавлять только при подтверждённой необходимости и с согласия пользователя.

Проверить, использует ли локальный декодер `beam_size=5` и `condition_on_previous_text=False`. Второй параметр уменьшает риск продолжения ошибочного текста из предыдущего фрагмента. Не добавлять неподдерживаемые YAML-поля: сверить доступные настройки с кодом своей версии. При отдельном запуске библиотеки эти параметры задаются напрямую.

Проверить выбор провайдера при ошибке: явный `provider: local` должен завершать обработку ошибкой, если локальный движок недоступен, без незаметной отправки записи в облако. Подтвердить это по реализации или безопасному изолированному тесту, не ломая рабочий шлюз.

Локальный Whisper сохраняет аудио на машине распознавания, но полученный текст может затем отправляться основному облачному провайдеру LLM. Это не полностью локальная обработка всей переписки.

## 4. Проверить работу через мессенджер

1. Попросить прислать новую нейтральную голосовую запись через рабочий мессенджер.
2. Найти относящиеся к ней строки журнала и подтвердить фактические провайдер, модель и язык. Не считать записанную конфигурацию доказательством её применения процессом.
3. Если процесс использует старые настройки или читает их только при запуске, предупредить о кратком перерыве и выполнить `hermes gateway restart` для нужного профиля.
4. После перезапуска проверить состояние шлюза и ещё одно новое голосовое сообщение.
5. Сверить текст с произнесённым. Отдельно проверить отрицания, время и суммы.

Не запускать второй шлюз с тем же токеном бота. Прямой вызов библиотеки на локальном файле не заменяет проверку входящего голосового сообщения. Текст, показанный клиентом Telegram, тоже не подтверждает работу распознавания в Hermes.

Вымышленные фразы для проверки:

- «Не отправляй письмо, сохрани черновик».
- «Встреча в четырнадцать тридцать, а не в пятнадцать».
- «Сумма двенадцать тысяч пятьсот рублей».
- «Открой Docker, затем проверь Python».

Для оценки качества по возможности проверить 10–20 новых записей: короткие команды, обычную речь, длинную запись с паузами, тихую речь и смешение языков. Одного удачного примера недостаточно для вывода об общей надёжности.

## 5. Повторно распознавать сомнительные записи

До ответа по существу, выполнения команды или сохранения фактов проверять транскрипцию на смысловые ошибки. Признаки: бессмысленные слова, случайные имена, невозможные действия, перепутанные участники, противоречивые суммы и время. Гладкий английский текст вместо русской речи также может быть ошибкой распознавания.

Порядок проверки:

1. Найти исходное аудио именно текущего сообщения. Сохранить исходную транскрипцию отдельно от исправленного варианта на время диагностики.
2. Повторить распознавание с явно указанным языком и `task="transcribe"`.
3. Если `medium` не восстановил смысл, проверить ту же запись через `large-v3` в пределах согласованных ресурсов.
4. Выполнить проход сильной модели без смысловой подсказки. При сохраняющейся неоднозначности сделать дополнительный проход с другой настройкой декодирования или коротким словарём устойчивых написаний.
5. Сравнить участников, действия, отрицания, числа, даты и обязательства. При необходимости выделить спорный фрагмент с небольшим контекстом по краям и проверить отдельно.
6. Если неоднозначность меняет действие или сохраняемый факт, запросить уточнение конкретного фрагмента. Не выполнять действие на основе догадки.

Два прохода одной модели могут повторить одну ошибку. Их совпадение повышает уверенность, но не является независимым подтверждением смысла.

Не подсказывать модели спорный глагол, сумму, отрицание или готовый ответ через `initial_prompt`. Повторение предложенной формулировки не доказывает, что она звучала в записи.

Если аудио недоступно, сообщить об этом и запросить повторную запись или уточнение. Не утверждать, что запись проверена, когда доступен только текст.

Пунктуацию и очевидные опечатки можно исправлять отдельно. Нельзя незаметно менять имена, суммы, обязательства и смысл. Если ошибка уже попала в сохранённые записи, после подтверждения правильного варианта исправить затронутые материалы в пределах разрешённого доступа.

## 6. Отдельное сравнение моделей

Для диагностики сохранить следующий код как `compare_stt.py` и выполнить его Python-интерпретатором Hermes. Он проверяет библиотеку напрямую; дополнительные фильтры шлюза могут отличаться.

```python
import argparse
import json
import time
from faster_whisper import WhisperModel

parser = argparse.ArgumentParser()
parser.add_argument("audio")
parser.add_argument("--model", default="medium")
parser.add_argument("--language", default="ru")
args = parser.parse_args()

started = time.perf_counter()
model = WhisperModel(args.model, device="cpu", compute_type="int8")
loaded = time.perf_counter()
segments, info = model.transcribe(
    args.audio,
    language=args.language,
    task="transcribe",
    beam_size=5,
    vad_filter=True,
    condition_on_previous_text=False,
    initial_prompt=None,
)
print(json.dumps({
    "model": args.model,
    "language": info.language,
    "language_probability": info.language_probability,
    "load_seconds": round(loaded - started, 2),
}, ensure_ascii=False), flush=True)
for segment in segments:
    print(json.dumps({
        "start": segment.start,
        "end": segment.end,
        "text": segment.text,
        "avg_logprob": segment.avg_logprob,
        "no_speech_prob": segment.no_speech_prob,
    }, ensure_ascii=False), flush=True)
print(json.dumps({
    "transcribe_seconds": round(time.perf_counter() - loaded, 2)
}), flush=True)
```

Запустить последовательно на одной и той же записи, подставив её фактический путь вместо `sample.ogg`:

```bash
"$HERMES_PYTHON" compare_stt.py sample.ogg --model medium --language ru
"$HERMES_PYTHON" compare_stt.py sample.ogg --model large-v3 --language ru
```

CPU и `int8` выбраны для переносимости. Ускоритель использовать после проверки совместимости. Долгие запуски выполнять как отслеживаемые фоновые процессы и читать результат после завершения.

Сравнивать точность формулировок на одинаковом аудио, меняя сначала один параметр. Вероятность языка не является оценкой точности слов. `avg_logprob` и `no_speech_prob` помогают найти подозрительные фрагменты, но не подтверждают смысл. Отдельно учитывать загрузку модели и время распознавания: первый запуск не отражает задержку прогретого процесса.

## 7. Условия завершения

Настройка считается проверенной, когда:

- `faster-whisper` доступен в окружении Python, которым пользуется Hermes;
- параметры записаны в нужный профиль, посторонние настройки сохранены;
- новое голосовое сообщение прошло через действующий шлюз с ожидаемыми провайдером, моделью и языком;
- полученная транскрипция сверена с записью, существенные ошибки перечислены;
- исключена автоматическая облачная передача аудио без разрешения.

В итоговом ответе указать применённую модель, язык, результат реальной проверки и оставшиеся ограничения. Если пока изменена только конфигурация или ожидается тестовая запись, прямо назвать этот статус. Не подменять результат пересказом инструкции или списком команд для самостоятельного выполнения.

Диагностические записи и тексты хранить локально с ограниченным доступом; срок хранения согласовать. Не включать частные данные в переносимые инструкции и не публиковать их.
